# PD-1 Swin on LungHist700

Deliverables in this folder:
- `runbook.md`: training and evaluation flow
- `baseline_comparison.csv`: published baseline vs your run
- `pd1_metrics.json`: generated by training script after run

Run:
```bash
python scripts/pd1_train_swin_lunghist700.py --data-dir data/lunghist700_binary --epochs 5 --batch-size 16 --lr 1e-4 --published-baseline 0.0000 --output reports/pd1/pd1_metrics.json
```
