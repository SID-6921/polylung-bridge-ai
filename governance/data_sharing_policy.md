# Data Sharing Policy

## Public Artifacts Allowed
- Open dataset-derived metrics (for example LungHist700)
- Published-paper-derived calculations (for example PSPII from extracted cytokine values)
- Integration benchmark telemetry (latency, success rate)

## Restricted Artifacts
- HBIL raw data, labels, images, and patient-level records
- HBIL internal metrics without explicit approval
- Any protected institutional material

## Claim Rule
Every quantitative claim in docs or presentations must map to:
1. Script used
2. Input source
3. Output artifact path
4. Approval status (`public` or `restricted`)
