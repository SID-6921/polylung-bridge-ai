# PD-3 — HBIL Clinical Cohort Validation

## Status: Data Unavailable for External Release

The Himalayan Institute of Medical Sciences (HBIL) clinical cohort was originally
identified as a potential source of real-world validation data for the PSPII index
(PD-3 in the R21 proposal).

**As of 2026-05-31, HBIL has declined to make any data or results available for
external sharing.** No metrics, model outputs, or patient-level values have been
provided to this project.

## What this means for the grant
- No PD-3 metric can be cited from this source at this time.
- The R21 proposal will note HBIL as a planned validation site pending data sharing
  agreement execution.
- A data use agreement (DUA) or institutional collaboration agreement is required
  before any HBIL-derived result can appear in publications or grant documents.

## Rules (unchanged)
- Do NOT store raw HBIL data in this repository.
- Do NOT store patient-level metrics.
- Do NOT cite HBIL performance values in grants or publications without explicit
  written approval from the HBIL PI.
- This folder contains policy notices only — no protected data is committed here.
